# NimNet Development Instructions

## Quick Reference

### Build & Test
```bash
nimble test          # Run all tests
nimble build         # Build the library
nimble doc           # Generate documentation
nim c -r tests/tgraph.nim  # Run a single test file
```

### Project Structure
- Source: `src/nimnet/` — each module is a separate `.nim` file
- Tests: `tests/t*.nim` — mirror source structure with `t` prefix
- ADRs: `docs/adr/` — architecture decision records

### Key Types
- `Graph[N]` — undirected graph, N is node type (must be hashable)
- `DiGraph[N]` — directed graph
- `EdgeAttr` = `Table[string, string]` — edge attributes
- `NodeAttr` = `Table[string, string]` — node attributes

### When Adding New Features
1. Check if an Issue exists; create one if not
2. Create feature branch from `main`
3. Implement in appropriate module under `src/nimnet/`
4. Write tests in `tests/`
5. Update `src/nimnet.nim` to export new module
6. Update CHANGELOG.md
7. Run `nimble test` to verify
8. Submit PR referencing the Issue

### Nim Tips for This Project
- Use `var g: Graph[N]` for mutable graph operations
- Use `g: Graph[N]` (no var) for read-only operations
- Edge iteration: `for (u, v) in g.edges` or `for (u, v, attr) in g.edgesWithAttr`
- Node iteration: `for n in g.nodes`
- Neighbor iteration: `for n in g.neighbors(node)`
- All public procs need `*` export marker
- Use `fmt` from `std/strformat` for error messages
